## 1,000-Student Seed Accounts (Full Dataset)
Every seeded account in the 1,000-student dataset uses password: `Password@123`

### Administrators
| Username | Role | Permission Set | Notes |
|----------|------|----------------|-------|
| `super.admin` / `admin_core` | Admin | Super_Admin, Core_Admin (all scopes) | Root admin |
| `finance.admin` / `admin_finance` | Admin | Finance_Admin | Fee dues & payments |
| `hr.admin` / `admin_hr` | Admin | HR_Admin | Leave approvals & payroll |
| `hostel.admin` / `admin_hostel` | Admin | Hostel_Admin | Room allocations & requests |
| `academics.admin` | Admin | Academics_Admin | Offerings & curriculum |
| `exams.admin` | Admin | Exams_Admin | Exam marks & publish results |

### Faculty
Faculty usernames use their employee format `emp0001` through `emp0080` (password: `Password@123`).

### Students
Student usernames use `s<batch><dept><seq>` (e.g., `s23cse0001`, `s24it0001`, `s25entc0001`, `s26mech0001`) with password: `Password@123`.
