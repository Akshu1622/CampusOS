# Seed Data & Demo Cohorts

This document outlines the volumes generated by `db/seed/generate_demo.py` and the SQL queries to verify the specific edge-case cohorts required.

## Volumes
- **Students**: 250
- **Departments**: 5
- **Programs**: 10
- **Terms**: 2 (Exactly one is_current=1)
- **Employees**: 30 (20 Faculty, 10 Staff)
- **Courses**: 50
- **Course Offerings**: 50
- **Enrollments**: 986 total
- **Hostels**: 2 (Total capacity 104)
- **Rooms**: 2

## Edge-Case Verification Queries

**1. Students with attendance at 100%, 75%, and 50% (mapped to 60-74%)**
```sql
-- 100% Attendance
SELECT enrollment_id, COUNT(*) as total, SUM(CASE WHEN status='PRESENT' THEN 1 ELSE 0 END) as present 
FROM attendance_record WHERE enrollment_id = 1 GROUP BY enrollment_id;

-- 75% Attendance
SELECT enrollment_id, COUNT(*) as total, SUM(CASE WHEN status='PRESENT' THEN 1 ELSE 0 END) as present 
FROM attendance_record WHERE enrollment_id = 2 GROUP BY enrollment_id;

-- 50% Attendance
SELECT enrollment_id, COUNT(*) as total, SUM(CASE WHEN status='PRESENT' THEN 1 ELSE 0 END) as present 
FROM attendance_record WHERE enrollment_id = 3 GROUP BY enrollment_id;
```

**2. Fee Payment States**
```sql
-- Fully Paid (Student 1)
SELECT id, status FROM student_fee WHERE student_id = 1;

-- Partly Paid (Student 2)
SELECT id, status FROM student_fee WHERE student_id = 2;

-- Overdue (Student 3)
SELECT id, status FROM student_fee WHERE student_id = 3;
```

**3. Students whose dues exceed the average (for RP-5)**
```sql
SELECT student_id, SUM(amount_due) as total_dues FROM student_fee
GROUP BY student_id
HAVING SUM(amount_due) > (SELECT AVG(amount_due) FROM student_fee);
```

**4. Hostel Occupancy**
```sql
-- 100% full hostel (Hostel 1, Room 1)
SELECT id, available_beds FROM room WHERE hostel_id = 1;

-- Room with exactly one bed left (Hostel 2, Room 1)
SELECT id, available_beds FROM room WHERE hostel_id = 2;
```

**5. Hostel Requests**
```sql
-- Active allocation (Student 5)
SELECT * FROM hostel_allocation WHERE student_id = 5;

-- Pending Request (Student 12)
SELECT * FROM hostel_request WHERE student_id = 12 AND status = 'PENDING';

-- Rejected Request (Student 13)
SELECT * FROM hostel_request WHERE student_id = 13 AND status = 'REJECTED';
```

**6. Leave Applications**
```sql
-- Full leave used (Employee 1, Casual Leave)
SELECT * FROM leave_application WHERE employee_id = 1;

-- Pending leave (Employee 2)
SELECT * FROM leave_application WHERE employee_id = 2 AND status = 'PENDING';
```

**7. Payroll Runs**
```sql
-- Finalized vs Non-finalized
SELECT payroll_month, status FROM payroll_run;
```

**8. Enrollments & Offerings**
```sql
-- Withdrawn enrollment
SELECT * FROM enrollment WHERE status = 'WITHDRAWN';

-- Offering at full capacity
SELECT id, capacity FROM course_offering WHERE id = 1;

-- Offering with open seats
SELECT id, capacity FROM course_offering WHERE id = 2;
```

**9. Exam Results**
```sql
-- Published results
SELECT * FROM exam_marks_result WHERE is_published = 1;

-- Multiple semester results for CGPA (Student 1)
SELECT student_id, COUNT(*) FROM semester_result WHERE student_id = 1 GROUP BY student_id;
```
